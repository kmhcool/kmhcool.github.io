# kmhcool.win

Personal portfolio for Thanawat (`kmhcool`), published with GitHub Pages.

## Local preview

The homepage is dependency-free:

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deployment

Push the `main` branch to `kmhcool/kmhcool.github.io`. GitHub Pages should
publish from the repository root. The `CNAME` file connects the site to
`kmhcool.win`.
